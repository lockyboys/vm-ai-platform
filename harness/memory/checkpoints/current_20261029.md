계약 정정 확정(2026-10-29 KST): MongoDB 연계 문서의 식별 계층은 mongodb_database_id=Level 2 MongoDB 데이터베이스 식별자, object_id=Level 3 문서 Repository Object 식별자, mongodb_collection_id=Level 3 MongoDB 컬렉션 식별자, mongodb_document_master_id=Level 4 문서 마스터 식별자이다. sp_object_execution_link의 동명 3개 필드를 연결 대상 MongoDB 문서 최상위 키로 저장하며 값은 link 행과 정확히 일치해야 한다. Level 4 ID는 Level 3 MCM class ID나 MongoDB _id를 재사용하지 않고 IdentifierCoordinator/reserve_document_master_id로 발급한다. 기존 fallback object_id와 기존 MCM Level3 ID를 document master ID로 재사용하는 규칙은 폐기한다. 생성 감사 필드는 실제 생성 시 created_dt, created_by, client_ip, program_id만 기록하고, 실제 수정/삭제가 없으면 updated/deleted 필드를 만들지 않는다. 기존 현대해상 문서는 이 계약으로 재검증하며, 불일치 시 정상 완료로 처리하지 않는다.
