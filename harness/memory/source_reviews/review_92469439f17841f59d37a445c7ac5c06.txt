## 1. 전문가적 견해 및 종합 평가

**검증 결론: 초안 4개 중 PARTNER안만 채택할 수 있습니다. 다만 근거 없이 바꾼 2건은 원복하고, 1건은 최소 변경으로 고쳐야 합니다.**

- **요청 형식 충족 여부:** PROMPT_ENGINEER, REVIEWER, BUG_HUNTER 안은 3번에 전체 소스가 없습니다. "3번에 수정된 전체 소스" 요구를 충족하지 못하므로 최종안으로 쓸 수 없습니다. 진단 근거로만 사용했습니다.
- **PARTNER안 대조 결과:** docstring 명세와 원본 코드를 함수별로 대조했습니다. 진단은 대부분 정확합니다. 다음 3가지는 수정이 필요합니다.
  1. **`LINE_SCORES[4]` 1000→1200:** 명세에 값이 없습니다. 테스트 기대값을 깰 수 있는 근거 없는 변경이므로 **원복**합니다.
  2. **`wall_kick` 기본 offsets 순서 변경:** 명세는 "offsets를 순서대로 시도"라고만 합니다. 기본값을 바꿀 근거가 없으므로 **원복**합니다. 실제 결함인 부호 오류와 None 미반환만 고칩니다.
  3. **`PIECES["T"]`:** 원본 `[[1,1,1],[1,0,0]]`은 L 모양이라 결함은 맞습니다. 교정은 원본 첫 행을 유지하는 최소 변경 `[[1,1,1],[0,1,0]]`으로 바꿉니다.
- **PARTNER안의 기타 사항:** 모듈 docstring에 넣은 "[수정 노트]"는 명세 문서를 바꾸는 것이므로 제거했습니다. 같은 내용을 주석으로 옮겼습니다.
- **초안 간 사실 오류:** REVIEWER는 "`GameState.level` 프로퍼티는 정상"이라고 했습니다. 그러나 docstring은 "시작 레벨 **+** 누적 줄로 오른 레벨"입니다. 원본의 `max(...)`는 명세 위반이므로 수정 대상이 맞습니다. 원본 `record_clear`도 `start_level + level_for_lines(...)`로 계산해 합산 해석을 뒷받침합니다.
- **점검 항목별 판정:**
  - **메모리:** 결함이 있습니다(P0).
    - `[[0]*cols]*rows` 때문에 모든 행이 같은 객체를 공유합니다.
    - `copy_board`가 얕은 복사입니다.
    - `place`가 원본을 직접 변경합니다.
    - `GameState(log=[])` 기본 인자를 모든 인스턴스가 공유합니다.
  - **동시성:** 스레드나 락 코드가 없습니다. 공유 가변 상태(log 기본값, 원본 변경)를 제거하면 충분합니다. 락 추가는 **수정 불필요**입니다.
  - **예외:** 명세는 `ValueError`인데 `IndexError`/`RuntimeError`를 던지거나 예외 없이 값을 반환하는 경로가 여러 곳 있습니다.
  - **리소스 해제:** 파일, 소켓, 락이 없습니다. **해당 없음, 수정 불필요**입니다.
  - **LangChain/LangGraph:** 경로명에만 나오고 소스에는 import나 사용이 없습니다. **PROMPT_ENGINEER 설계 검토는 해당 없음**입니다.
- **실행 여부:** 코드와 bench(`harness/tests/selffix_hard/`)는 실행하지 않았습니다. 판정은 정적 대조와 손 추적 결과입니다.
  - 손 추적 1: `rotate_cw([[1,2],[3,4]])` → `[[3,1],[4,2]]`
  - 손 추적 2: 빈 20x10 보드에 I 조각을 `hard_drop`하면 착지 19행, 낙하 19칸

```python
"""시연용 테트리스 엔진(화면 없음) (스스로 고치는 리뷰 앱 어려운 시험용, 2026-11-11).

보드는 rows x cols 리스트(0=빈칸, 1=블록), 조각은 0/1 2차원 리스트. top은 행, left는 열(0부터).
각 함수의 docstring이 명세다. 입력 보드·조각은 바꾸지 않고 새 객체를 돌려준다.
테스트: harness/tests/selffix_hard/ 아래 bench 파일.
"""
# 수정 노트: 모든 함수는 입력을 변경하지 않으며 반환 보드의 행은 서로 다른 리스트 객체다.
# 외부 I/O·파일·락이 없어 해제할 리소스는 없다. GameState는 스레드 안전을 약속하지 않는다.
import random

# S=Z, J=L 중복과 L 모양이던 T를 최소 변경으로 교정(모양 정의는 명세에 없어 미확인).
PIECES = {
    "I": [[1, 1, 1, 1]],
    "O": [[1, 1], [1, 1]],
    "T": [[1, 1, 1], [0, 1, 0]],
    "S": [[0, 1, 1], [1, 1, 0]],
    "Z": [[1, 1, 0], [0, 1, 1]],
    "J": [[1, 0, 0], [1, 1, 1]],
    "L": [[0, 0, 1], [1, 1, 1]],
}
LINE_SCORES = [0, 40, 100, 300, 1000]
# 명세 "10줄마다 1"에 맞춤(원본 8은 명세 위반).
LINES_PER_LEVEL = 10


# ---------------------------------------------------------------- 보드
def new_board(rows=20, cols=10):
    """빈 보드. rows·cols는 1 이상 정수, 아니면 ValueError."""
    for value in (rows, cols):
        if not isinstance(value, int) or isinstance(value, bool) or value < 1:
            raise ValueError("rows and cols must be positive integers")
    # 행마다 새 리스트(원본 [[0]*cols]*rows는 모든 행이 같은 객체였다).
    return [[0] * cols for _ in range(rows)]


def copy_board(board):
    """행까지 새로 만든 복사본."""
    return [list(row) for row in board]


def board_to_text(board):
    """블록은 '#', 빈칸은 '.'으로 한 줄씩, 줄 사이는 '\\n'."""
    return "\n".join("".join("#" if cell else "." for cell in row) for row in board)


def text_to_board(text):
    """board_to_text의 역변환. 빈 문자열, 길이가 다른 줄, '#'/'.' 이외 문자는 ValueError."""
    if not text:
        raise ValueError("empty text")
    lines = text.splitlines()
    width = len(lines[0])
    if width == 0:
        raise ValueError("ragged board text")
    board = []
    for line in lines:
        if len(line) != width:
            raise ValueError("ragged board text")
        if any(ch not in "#." for ch in line):
            raise ValueError("invalid character in board text")
        board.append([1 if ch == "#" else 0 for ch in line])
    return board


# ---------------------------------------------------------------- 조각
def rotate_cw(piece):
    """시계 방향 90도: 위쪽 행이 오른쪽 열이 된다."""
    return [list(row) for row in zip(*piece[::-1])]


def rotate_ccw(piece):
    """반시계 방향 90도: 위쪽 행이 왼쪽 열이 된다(뒤집힌 순서)."""
    return [list(row) for row in zip(*piece)][::-1]


def rotate_180(piece):
    """180도: 행 순서와 각 행의 칸 순서를 모두 뒤집는다."""
    return [list(row)[::-1] for row in piece[::-1]]


def piece_cells(piece):
    """블록 칸의 (행, 열) 목록(행 우선, 왼쪽부터)."""
    return [(r, c) for r, row in enumerate(piece) for c, cell in enumerate(row) if cell]


def trim_piece(piece):
    """바깥쪽의 빈 행·빈 열을 잘라낸다. 블록이 하나도 없으면 ValueError."""
    cells = piece_cells(piece)
    if not cells:
        raise ValueError("piece has no blocks")
    top = min(r for r, _ in cells)
    bottom = max(r for r, _ in cells)
    left = min(c for _, c in cells)
    right = max(c for _, c in cells)
    # bottom/right는 포함 범위이므로 +1.
    return [list(row[left:right + 1]) for row in piece[top:bottom + 1]]


def piece_size(piece):
    """(높이, 너비)."""
    return len(piece), len(piece[0])


# ---------------------------------------------------------------- 놓기·지우기
def can_place(board, piece, top, left):
    """조각의 블록 칸이 모두 보드 안이고 기존 블록과 겹치지 않으면 True(빈칸은 밖에 있어도 된다)."""
    rows, cols = len(board), len(board[0])
    for r, c in piece_cells(piece):
        y, x = top + r, left + c
        if y < 0 or y >= rows or x < 0 or x >= cols:
            return False
        if board[y][x]:
            return False
    return True


def place(board, piece, top, left):
    """조각을 놓은 새 보드. 놓을 수 없으면 ValueError. 조각의 빈칸은 기존 블록을 지우지 않는다."""
    if not can_place(board, piece, top, left):
        raise ValueError("piece cannot be placed at the given position")
    result = copy_board(board)
    for r, c in piece_cells(piece):
        result[top + r][left + c] = 1
    return result


def full_rows(board):
    """가득 찬 행 번호 목록(오름차순)."""
    return [y for y, row in enumerate(board) if all(row)]


def clear_lines(board):
    """가득 찬 행을 지우고 위에 빈 행을 채운 (새 보드, 지운 행 수). 높이·너비는 그대로."""
    cols = len(board[0])
    kept = [list(row) for row in board if not all(row)]
    cleared = len(board) - len(kept)
    return [[0] * cols for _ in range(cleared)] + kept, cleared


def drop_row(board, piece, left, top=0):
    """top에서 아래로 떨어뜨렸을 때 멈추는 행. 시작 위치에 놓을 수 없으면 ValueError."""
    if not can_place(board, piece, top, left):
        raise ValueError("piece cannot be placed at the start position")
    # 막힐 때까지 반복(보드 높이가 유한하므로 반드시 종료).
    while can_place(board, piece, top + 1, left):
        top += 1
    return top


def hard_drop(board, piece, left, top=0):
    """끝까지 떨어뜨려 놓고 줄을 지운 (새 보드, 떨어진 칸 수, 지운 행 수)."""
    landing = drop_row(board, piece, left, top)
    # 먼저 놓은 뒤 줄을 지운다(원본은 순서가 반대였다).
    placed = place(board, piece, landing, left)
    cleared_board, cleared = clear_lines(placed)
    return cleared_board, landing - top, cleared


def shift(board, piece, top, left, dx):
    """좌우로 dx칸 옮길 수 있으면 새 left, 막히면 원래 left(한 번에 dx칸, 중간 칸은 보지 않는다)."""
    if can_place(board, piece, top, left + dx):
        return left + dx
    return left


def wall_kick(board, piece, top, left, offsets=((0, -1), (0, 0), (0, 1), (-1, 0))):
    """offsets(행, 열 이동)를 순서대로 시도해 처음 놓을 수 있는 (top, left). 모두 막히면 None."""
    for dy, dx in offsets:
        if can_place(board, piece, top + dy, left + dx):
            return top + dy, left + dx
    return None


def is_game_over(board, piece, left):
    """맨 위(top=0)에 조각을 놓을 수 없으면 True."""
    return not can_place(board, piece, 0, left)


# ---------------------------------------------------------------- 보드 분석
def column_heights(board):
    """열마다 맨 위 블록부터 바닥까지의 높이(블록이 없으면 0)."""
    rows = len(board)
    heights = []
    for x in range(len(board[0])):
        height = 0
        for y in range(rows):
            if board[y][x]:
                height = rows - y
                break
        heights.append(height)
    return heights


def aggregate_height(board):
    """열 높이의 합."""
    return sum(column_heights(board))


def max_height(board):
    """가장 높은 열의 높이."""
    return max(column_heights(board))


def count_holes(board):
    """구멍 수: 어떤 열에서 블록 아래에 있는 빈칸."""
    holes = 0
    for x in range(len(board[0])):
        seen_block = False
        for y in range(len(board)):
            if board[y][x]:
                seen_block = True
            elif seen_block:
                holes += 1
    return holes


def bumpiness(board):
    """이웃한 열 높이 차이의 절댓값 합."""
    heights = column_heights(board)
    return sum(abs(heights[i] - heights[i + 1]) for i in range(len(heights) - 1))


# ---------------------------------------------------------------- 점수·레벨
def score_for_lines(cleared, level):
    """한 번에 지운 줄 수(0~4)의 점수 = LINE_SCORES[cleared] * (level + 1).
    cleared가 0~4가 아니거나 level이 음수면 ValueError."""
    if not isinstance(cleared, int) or cleared < 0 or cleared > 4:
        raise ValueError("cleared must be between 0 and 4")
    if level < 0:
        raise ValueError("level must not be negative")
    return LINE_SCORES[cleared] * (level + 1)


def level_for_lines(total_lines):
    """누적 줄 수로 레벨(10줄마다 1). 음수면 ValueError."""
    if total_lines < 0:
        raise ValueError("total_lines must not be negative")
    return total_lines // LINES_PER_LEVEL


def lines_to_next_level(total_lines):
    """다음 레벨까지 남은 줄 수(1~10)."""
    return LINES_PER_LEVEL - total_lines % LINES_PER_LEVEL


def gravity_frames(level):
    """한 칸 떨어지는 데 걸리는 프레임: 48 - 5*level, 최소 1."""
    return max(1, 48 - 5 * level)


def combo_bonus(combo, level):
    """연속으로 줄을 지운 횟수 combo(1부터)의 보너스 = 50 * combo * (level + 1). combo가 0 이하면 0."""
    if combo <= 0:
        return 0
    return 50 * combo * (level + 1)


def bag_sequence(count, seed):
    """7-bag 순서: 7종을 한 묶음씩 섞어 이어 붙인 앞 count개(seed가 같으면 같은 순서). count < 0이면 ValueError."""
    if count < 0:
        raise ValueError("count must not be negative")
    # 인스턴스 RNG에 seed 적용(재현성, 전역 random 상태 불변).
    rng = random.Random(seed)
    sequence = []
    while len(sequence) < count:
        # 조각 이름을 사용해 전역 PIECES 행렬 aliasing을 막는다(반환 형식은 bench로 미확인).
        bag = list(PIECES.keys())
        rng.shuffle(bag)
        sequence.extend(bag)
    return sequence[:count]


# ---------------------------------------------------------------- 게임 상태
class GameState:
    """점수·줄 수·콤보·보관(hold)을 관리한다. 인스턴스마다 상태를 따로 가진다."""

    def __init__(self, level=0, log=None):
        # 가변 기본값(log=[])은 모든 인스턴스가 공유하므로 None 패턴으로 교체.
        self.score = 0
        self.lines = 0
        self.start_level = level
        self.combo = 0
        self.held = None
        self.can_hold = True
        self.log = [] if log is None else log

    @property
    def level(self):
        """시작 레벨 + 누적 줄로 오른 레벨."""
        return self.start_level + level_for_lines(self.lines)

    def record_clear(self, cleared):
        """조각 하나를 놓은 뒤 지운 줄 수를 반영한다. 점수는 반영 전 레벨로 계산한다.
        지웠으면 combo += 1 후 줄 점수 + 콤보 보너스(2번째 연속부터, combo-1 기준), 못 지웠으면 combo = 0.
        놓을 때마다 다시 보관할 수 있게 된다. 반환: 이번에 얻은 점수."""
        level = self.level
        # 잘못된 cleared는 여기서 ValueError가 나며 상태 변경 전이라 오염되지 않는다.
        gained = score_for_lines(cleared, level)
        if cleared > 0:
            self.combo += 1
            gained += combo_bonus(self.combo - 1, level)
        else:
            self.combo = 0
        self.lines += cleared
        self.score += gained
        self.can_hold = True
        self.log.append((cleared, gained))
        return gained

    def hold(self, current):
        """현재 조각 이름을 보관하고 이전 보관 조각(없으면 None)을 돌려준다.
        한 번 놓기 전에 두 번 보관하면 ValueError."""
        if not self.can_hold:
            raise ValueError("cannot hold twice before placing a piece")
        previous, self.held = self.held, current
        self.can_hold = False
        return previous
```
