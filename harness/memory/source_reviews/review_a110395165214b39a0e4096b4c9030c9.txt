## 1. 전문가적 견해 및 종합 평가

### 초안 검증 및 종합 평가
제시된 초안(PROMPT_ENGINEER, REVIEWER, PARTNER)은 정적 분석 기반의 무결성 검증 파이프라인이라는 모듈의 목적을 대체로 잘 이해하고 개선 방향을 제시했습니다. 특히 REVIEWER가 지적한 **"독스트링(`Expr(Constant)`) 변경만으로 AST 차이를 발생시켜 실제 실행 코드를 수정하지 않고 우회하는 취약점"**과 PARTNER가 지목한 **"표준 라이브러리 서브모듈 과다 허용(`os.invalid_mod` 환각)"** 및 **"코드 블록 정규식 탐욕 매칭 오류"**는 프로덕션 환경에서 발생할 수 있는 중대한 결함입니다.

그러나 초안 간의 상충 및 누락 사항이 다음과 같이 확인되었습니다:
1. **REVIEWER 지적 사항의 PARTNER 구현 누락**: REVIEWER는 독스트링 우회 방지를 위한 실행 노드 분리(`_extract_executable_body`)와 괄호 표기 허용 정규식(`re.findall(r"`([A-Za-z_][A-Za-z0-9_]*)(?:\(\))?`")`)을 명확히 요구했으나, PARTNER의 최종 소스 코드 구현에서는 `ast.dump(old) != ast.dump(new)`를 그대로 사용하여 독스트링 변경만으로 검증을 우회할 수 있는 보안 취약점이 여전히 방치되었습니다.
2. **`build_review_query` 변경 위험 격리**: PROMPT_ENGINEER가 제안한 경계 태그(`<source_code>`) 도입은 계약된 헤딩 구조(`HEADINGS`)와 프롬프트 인터페이스 규격을 변경시킬 위험이 있어, 공개 API 안정성을 위해 원본 인터페이스를 보존하면서도 검증 파서(`source_block`)의 정규식 견고성을 높이는 방향이 타당합니다.

### 검증 근거 및 미확인 사항
* **근거**:
  * 파이썬의 `ast.dump()`는 독스트링 노드(`ast.Expr(value=ast.Constant(value='...'))`)의 변화도 AST 트리의 변화로 인식합니다. 따라서 "주석과 표현만 바꾼 코드는 수정으로 간주하지 않는다"는 계약을 강제하려면 함수 본문 첫 문장의 문자열 상수를 제외한 실행 노드 덤프를 대조해야 합니다.
  * `re.findall(r"`([A-Za-z_][A-Za-z0-9_]*)`", line)`는 LLM이 진단 표에 `` `func_name()` `` 형태로 괄호를 붙여 기재했을 때 함수명을 캡처하지 못하고 누락합니다.
  * `_module_exists`에서 `top in sys.stdlib_module_names`만 확인하면 `os.non_existent`와 같은 서브모듈 환각을 걸러내지 못하므로, 서브모듈은 `os.path` 등 가상 모듈을 제외하고 실제 경로 검사를 거쳐야 합니다.
* **미확인 사항**:
  * 정적 컴파일된 커스텀 임베디드 파이썬 환경이나 ziparchive 내부에 패키징된 C 확장 모듈의 경우 파일 시스템 경로 기반 존재 검사 시 오탐(부재로 판정)될 가능성이 있으나, 표준 `sys.path` 배포 환경에서는 정상 동작함을 확인했습니다.

def source_block(text: str) -> str:
    """소스 문자열 안의 예시 fence를 위해 마지막 닫는 fence까지 읽되,
    후속 텍스트나 타 언어 블록으로 문법 오류 발생 시 점진적으로 유효한 최장 블록을 탐색합니다.
    """
    start_match = re.search(r"```python[ \t]*\r?\n", text)
    if not start_match:
        return ""

    code_start = start_match.end()
    remaining = text[code_start:]

    fence_pattern = re.compile(r"(?:\r?\n)```[ \t]*(?:\r?\n|$)")
    fence_matches = list(fence_pattern.finditer(remaining))
    if not fence_matches:
        return ""

    # 1. 중첩 fence 예시 보존을 위해 가장 마지막 fence까지를 우선 추출하여 AST 검증
    longest_candidate = remaining[:fence_matches[-1].start()]
    try:
        ast.parse(longest_candidate)
        return longest_candidate
    except SyntaxError:
        pass

    # 2. 후속 마크다운 블록이 합쳐져 파싱 실패 시, 뒤에서부터 유효한 파이썬 AST 블록을 탐색
    for fence in reversed(fence_matches[:-1]):
        candidate = remaining[:fence.start()]
        try:
            ast.parse(candidate)
            return candidate
        except SyntaxError:
            continue

    return longest_candidate


def normalize_plan(plan: Sequence[str], query: str, maximum: int) -> List[str]:
    """필수 설계 담당과 최종 구현 담당이 상한 때문에 사라지지 않게 합니다."""
    if maximum < 1:
        raise ValueError("Persona budget must be positive")
    plan_dedup = list(dict.fromkeys(plan))
    required = ["PROMPT_ENGINEER"] if any(x in query.lower() for x in ("langchain", "langgraph")) else []
    if wants_full_source(query):
        if required and maximum < 2:
            raise ValueError("Full LangGraph review requires at least two personas")
        others = [p for p in plan_dedup if p not in required and p != "PARTNER"]
        return (required + others)[:maximum - 1] + ["PARTNER"]
    return (required + [p for p in plan_dedup if p not in required])[:maximum] or ["REVIEWER"]

def _module_references(tree: Optional[ast.AST]) -> Set[str]:
    """소스가 참조하는 절대 모듈 이름을 모은다.

    - `import a.b` / `from a.b import c` (상대 import는 위치에 따라 달라지므로 제외)
    - 리스트·튜플 안의 `"-m", "a.b"` 문자열 쌍(서브프로세스로 띄우는 모듈 경로)
    """
    if tree is None:
        return set()

    names = set()
    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            names.update(alias.name for alias in node.names)
        elif isinstance(node, ast.ImportFrom) and node.level == 0 and node.module:
            names.add(node.module)
        elif isinstance(node, (ast.List, ast.Tuple)):
            items = node.elts
            for first, second in zip(items, items[1:]):
                if (isinstance(first, ast.Constant) and first.value == "-m"
                        and isinstance(second, ast.Constant) and isinstance(second.value, str)):
                    names.add(second.value)
    return names


def _module_exists(name: str, roots: Sequence[Any]) -> bool:
    """모듈을 import(실행)하지 않고 파일 시스템 경로 및 빌트인 명단만으로 존재 여부를 판단합니다.

    표준 라이브러리·내장 모듈은 단일 식별자(최상위 이름)만 즉각 인정하며,
    서브모듈은 알려진 가상 모듈(os.path 등)을 제외하고 파일 시스템에서 실존 여부를 검증합니다.
    """
    parts = name.split(".")
    if not all(part.isidentifier() for part in parts):
        return False  # 모듈 이름으로 쓸 수 없는 문자열은 존재하지 않는 것으로 본다.

    top = parts[0]
    stdlib_names = getattr(sys, "stdlib_module_names", ())
    if len(parts) == 1:
        if top in sys.builtin_module_names or top in stdlib_names:
            return True
    else:
        if name in _STDLIB_SPECIAL_SUBMODULES:
            return True

    seen_roots: Set[Path] = set()
    for root in roots:
        try:
            base = Path(root).resolve() if root else Path.cwd().resolve()
            if base in seen_roots or not base.is_dir():
                continue
            seen_roots.add(base)

            curr_dir = base
            for index, part in enumerate(parts):
                last = (index == len(parts) - 1)
                target_dir = curr_dir / part
                if last:
                    if target_dir.is_dir() or any((curr_dir / f"{part}{s}").is_file() for s in _MODULE_SUFFIXES):
                        return True
                elif not target_dir.is_dir():
                    break  # 중간 패키지가 없으면 이 루트에서는 찾을 수 없다.
                curr_dir = target_dir
        except (OSError, RuntimeError, ValueError):
            # 권한 거부, 깨진 심볼릭 링크 순환, 잘못된 경로 예외 발생 시 안전하게 건너뜀
            continue
    return False


def unresolved_imports(
    code_tree: Optional[ast.AST],
    original_tree: Optional[ast.AST],
    roots: Sequence[Any]
) -> List[str]:
    """제안 소스에서 새로 깨진 import만 돌려준다.

    원본에서도 해석되지 않던 모듈(선택 의존성 등)은 제안 탓이 아니므로 제외한다.
    """
    if code_tree is None:
        return []

    safe_roots = tuple(roots)
    original_missing: Set[str] = set()
    if original_tree is not None:
        original_missing = {n for n in _module_references(original_tree) if not _module_exists(n, safe_roots)}
    return sorted(n for n in _module_references(code_tree)
                  if n not in original_missing and not _module_exists(n, safe_roots))


def _executable_ast_signature(func_node: ast.AST) -> Tuple[Any, ...]:
    """함수의 독스트링을 제외한 실행 노드 및 시그니처 덤프를 반환합니다.
    주석이나 설명문만 수정한 우회 코드를 검출하기 위함입니다.
    """
    if not isinstance(func_node, (ast.FunctionDef, ast.AsyncFunctionDef)):
        return (ast.dump(func_node),)

    decorators = [ast.dump(d) for d in func_node.decorator_list]
    args = ast.dump(func_node.args)
    returns = ast.dump(func_node.returns) if func_node.returns else ""

    body = func_node.body
    # 첫 번째 문장이 문자열 리터럴(독스트링)인 경우 실행 로직 비교에서 제외
    if (body and isinstance(body[0], ast.Expr)
            and isinstance(body[0].value, ast.Constant)
            and isinstance(body[0].value.value, str)):
        body = body[1:]

    body_dump = [ast.dump(stmt) for stmt in body]
    return (decorators, args, returns, tuple(body_dump))


def _collect_functions_scoped(tree: ast.AST) -> Dict[str, ast.AST]:
    """AST 내의 함수 정의 노드를 고유 스코프 경로를 부여하여 수집합니다."""
    functions: Dict[str, ast.AST] = {}

    def _traverse(node: ast.AST, scope: str) -> None:
        for child in ast.iter_child_nodes(node):
            if isinstance(child, (ast.FunctionDef, ast.AsyncFunctionDef)):
                func_path = f"{scope}.{child.name}" if scope else child.name
                functions[func_path] = child
                _traverse(child, func_path)
            elif isinstance(child, ast.ClassDef):
                class_path = f"{scope}.{child.name}" if scope else child.name
                _traverse(child, class_path)

    _traverse(tree, "")
    return functions


def validate_review(text: str, query: str, search_roots: Optional[Sequence[Any]] = None) -> List[str]:
    """제목·문법·기존 최상위 심볼을 확인하며 모델의 내용 정확성까지 보증하지는 않습니다."""
    if not wants_full_source(query):
        return []
    errors: List[str] = ["누락 제목: " + h for h in HEADINGS if h not in text]
    positions = [text.find(h) for h in HEADINGS]
    if not errors and positions != sorted(positions):
        errors.append("제목 순서 오류")
    code = source_block(text[text.find(HEADINGS[2]):]) if HEADINGS[2] in text else ""
    if not code:
        return errors + ["닫힌 전체 Python 코드 블록 없음"]
    try:
        tree = ast.parse(code)
    except SyntaxError as error:
        return errors + ["수정 소스 문법 오류: " + error.msg]
    if any(isinstance(n, ast.Constant) and n.value is Ellipsis for n in ast.walk(tree)):
        errors.append("생략 기호 Ellipsis 발견")
    original = source_block(query)
    try:
        old = ast.parse(original)
    except SyntaxError:
        old = None
    if old:
        kinds = (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)
        missing = {n.name for n in old.body if isinstance(n, kinds)} - {n.name for n in tree.body if isinstance(n, kinds)}
        if missing:
            errors.append("기존 공개 심볼 누락: " + ", ".join(sorted(missing)))

        # 진단 표가 기존 함수를 수정 대상으로 지목했다면 실제 함수 본문 변화를 확인합니다.
        if all(position >= 0 for position in positions):
            diagnosis = text[positions[1] + len(HEADINGS[1]):positions[2]]
            old_functions = _collect_functions_scoped(old)
            new_functions = _collect_functions_scoped(tree)

            # 단순 함수 이름 집합 생성
            old_names_to_scoped: Dict[str, List[str]] = {}
            for scoped_name in old_functions:
                bare_name = scoped_name.split(".")[-1]
                old_names_to_scoped.setdefault(bare_name, []).append(scoped_name)

            # 라인 단위로 '수정 불필요', '수정불필요', '수정 불요' 등으로 판정된 심볼은 제외하고
            # 실제 수정 대상으로 지목된 함수 심볼만 추출합니다 (선택적 괄호 표기 `func()` 허용).
            target_names = set()
            no_fix_pattern = re.compile(r"수정\s*(?:불필요|불요|없음)|변경\s*불필요", re.IGNORECASE)
            func_pattern = re.compile(r"`([A-Za-z_][A-Za-z0-9_]*)(?:\(\))?`")
            for line in diagnosis.splitlines():
                line_funcs = set(func_pattern.findall(line)) & old_names_to_scoped.keys()
                if line_funcs and not no_fix_pattern.search(line):
                    target_names.update(line_funcs)

            # 지목된 함수 중 실행 코드가 실제로 변경되지 않은 함수를 검출합니다 (독스트링만 바꾼 우회 차단).
            if target_names:
                unmodified = []
                for name in sorted(target_names):
                    scoped_paths = old_names_to_scoped.get(name, [])
                    changed = False
                    for path in scoped_paths:
                        if path not in new_functions:
                            changed = True  # 함수가 리팩터링되거나 위치·시그니처가 변경된 경우
                            break
                        if _executable_ast_signature(old_functions[path]) != _executable_ast_signature(new_functions[path]):
                            changed = True
                            break
                    if not changed:
                        unmodified.append(name)

                if unmodified:
                    errors.append("진단된 함수 수정 미반영: " + ", ".join(unmodified))

    # 문법이 맞아도 존재하지 않는 모듈을 참조하면 실행 즉시 실패하므로 오류로 본다.
    # 멀티스레드 환경 동시성 보호를 위해 sys.path의 불변 스냅샷을 생성합니다.
    current_sys_path = tuple(sys.path)
    roots = list(search_roots) if search_roots is not None else [_DEFAULT_PROJECT_ROOT, *current_sys_path]
    missing_modules = unresolved_imports(tree, old, roots)
    if missing_modules:
        errors.append("존재하지 않는 import 대상: " + ", ".join(missing_modules))
    return errors
```
Direct use of automatic function calling (AFC) in Models.generate_content is not recommended. Instead, we recommend to use AFC in Chat.send_message. Similarly, direct use of AFC in Models.generate_content_stream is not recommended. Instead, we recommend to use AFC in Chat.send_message_stream.
